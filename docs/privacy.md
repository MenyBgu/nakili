# פרטיות בקצרה

נקי-לי נבנתה כדי לעזור בניהול מטלות בית, לא כדי לאסוף מידע אישי. אין צורך
להזין שם מלא, מספר תעודת זהות, כתובת או פרטי קשר.

במצב המקומי, המידע נשמר ב־Local Storage בדפדפן בלבד. במצב Production, נתוני
הבית נשמרים ב־Supabase ומופרדים לפי `household_id` באמצעות RLS. המאגר הציבורי
ב־GitHub מכיל את קוד האפליקציה והתיעוד בלבד; הוא אינו מאגר נתוני משתמשים.

קוד הבית הוא סוד גישה. כל מי שמחזיק בו יכול להצטרף לבית, ולכן יש לשתף אותו רק
עם בני הבית ולהחליף אותו אם נחשף. הייצוא מההגדרות הוא פעולה ידנית, והקובץ
נשאר אצל המשתמש ואינו נשלח לשירות חיצוני.
