# נקי-לי (Nakili)

נקי-לי היא אפליקציית Web קטנה, בעברית וב־RTL, לניהול מטלות ניקיון שבועיות
בבית. בוחרים מטלה, מסמנים באילו ימים היא חוזרת, ומקבלים שבוע ברור שאפשר
לסמן ממנו ביצוע בלחיצה.

## מה יש ב־MVP

- תצוגת שבוע ראשון–שבת עם תאריך, היום הנוכחי והתקדמות.
- מטלות חוזרות לפי כמה ימים בשבוע ומטלות חד־פעמיות.
- סימון ביצוע, ביטול ביצוע ודילוג על מופע יחיד.
- חלוקת אחריות אופציונלית בין בני הבית.
- קוד בית אקראי במקום תעודת זהות או מידע אישי.
- מצב מקומי מלא ללא חשבונות, כדי להריץ את הפרויקט מיד.
- Supabase Anonymous Auth, Postgres ו־RLS במצב Production.
- ייצוא JSON/CSV מקומי.

## הרצה מקומית

דרישות: Node.js 20 ומעלה.

```bash
npm install
npm run dev
```

פתחו את `http://localhost:3000`. ללא משתני סביבה האפליקציה פועלת במצב
מקומי והמידע נשמר ב־Local Storage של הדפדפן.

## הפעלה עם Supabase

1. צרו פרויקט חינמי ב־Supabase והפעילו Anonymous Sign-ins.
2. העתיקו `.env.example` ל־`.env.local`.
3. הגדירו את כתובת הפרויקט, מפתח ה־anon ומפתח ה־service role.
4. הריצו את `supabase/migrations/0001_initial_schema.sql` ב־SQL Editor.
5. הפעילו:

```bash
npm run dev
```

מפתח `SUPABASE_SERVICE_ROLE_KEY` משמש רק ב־Route Handlers בצד השרת. אין
להוסיף אותו לקוד הדפדפן או למאגר.

## פריסה חינמית

המלצה: לחבר את מאגר GitHub ל־Vercel Hobby ולהגדיר שם את שלושת משתני הסביבה.
המאגר הציבורי מיועד לקוד ולתיעוד בלבד. נתוני הבתים נשמרים ב־Supabase ואינם
נכתבים ל־GitHub. שכבות חינם כפופות למכסות ולתנאי הספקים; פרויקט Supabase
חינמי עשוי להיעצר לאחר תקופה ללא פעילות.

## פרטיות ואבטחה

אין להזין תעודת זהות, כתובת, פרטים רפואיים או מידע רגיש. קוד הבית הוא מפתח
גישה מסוג bearer secret: כל מי שמחזיק בו יכול להצטרף לבית. במקרה של חשיפה,
החליפו אותו במסך ההגדרות. לפרטים נוספים ראו [`SECURITY.md`](SECURITY.md) ואת
[`docs/privacy.md`](docs/privacy.md).
